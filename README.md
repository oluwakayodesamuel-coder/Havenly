# Havenly

Everyday cleaning, made easy. A cleaning and hygiene booking platform for Lagos.
Built by Cascade Pod II at Webbo3 Academy, Frontend Development.

Deployed by: Ojo Oluwakayode Samuel

Live site: https://oluwakayodesamuel-coder.github.io/Havenly/

## What it is

A plain HTML, CSS and JavaScript website. No build step: every page is a file you can open.
The data (and everything that happens when you book, buy or sign in) comes from the live
Havenly API on webbo3.com, so the site works wherever it is hosted.

## Run it on your computer

Double-click `index.html`.

## Put it online

GitHub repository, then Settings, Pages, Deploy from a branch, main, / (root), Save.
